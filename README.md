# 🎌 Anime Recommendation System

A Python-based Anime Recommendation System that recommends similar anime based on genre and content similarity.

## 📌 Project Overview

This project is designed to help anime lovers discover new anime based on their interests. It uses Machine Learning techniques to find and recommend similar anime.

## 🚀 Features

- Anime Recommendation System
- Content-Based Filtering
- Genre-Based Similarity
- Cosine Similarity Algorithm
- Python-based implementation
- Anime dataset using CSV

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- CountVectorizer
- Cosine Similarity
- Pickle

## 🧠 How It Works

1. Loads anime data from the CSV dataset.
2. Processes anime genres.
3. Converts text data into numerical vectors using CountVectorizer.
4. Calculates similarity using Cosine Similarity.
5. Recommends similar anime based on the selected anime.

## 📊 Dataset

The project uses an anime dataset containing anime IDs, names, and genres.

To build a simple and effective Anime Recommendation System using Python and Machine Learning concepts.
